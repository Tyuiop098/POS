POS Mart — ระบบแคชเชียร์

ตั้งค่าเริ่มต้น

เชื่อมมือถือ (ตัวสแกนบาร์โค้ด) กับคอมพิวเตอร์ (แคชเชียร์) เข้าด้วยกัน โดยพิมพ์ รหัสร้านค้าเดียวกัน ทั้งสองเครื่อง ข้อมูลจะซิงก์กันแบบเรียลไทม์ผ่าน Firebase (ฟรี)

1) ตั้งค่า Firebase (ทำครั้งเดียวต่อเครื่อง)

สร้างโปรเจกต์ฟรีที่ console.firebase.google.com → เปิดใช้ Realtime Database (โหมดทดสอบ) → ไปที่ Project settings → คัดลอกค่า firebaseConfig ทั้งก้อนมาวางด้านล่าง (ดูขั้นตอนละเอียดใน README.md)

✓ รูปแบบข้อมูลถูกต้อง

2) รหัสร้านค้า

ตั้งรหัสอะไรก็ได้ (เช่น เลข 4-6 หลัก) แล้วพิมพ์รหัสเดียวกันทั้งบนคอมและมือถือ เพื่อให้ทั้งสองเครื่องอยู่ในร้านเดียวกัน

3) เครื่องนี้ทำหน้าที่อะไร

ข้อมูลตั้งค่านี้เก็บไว้ในเครื่องนี้เท่านั้น (localStorage) — ต้องตั้งค่าใหม่ทุกเครื่องที่ใช้งาน
